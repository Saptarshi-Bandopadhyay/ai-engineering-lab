# AI Workspace

## Overview

AI Workspace is a web application where authenticated users can manage AI conversations. The long-term vision is to build a production-ready AI platform similar to ChatGPT or Claude.

Version 1 focuses only on backend infrastructure and conversation management.

---

## Target Users

- Individual users
- Developers
- AI enthusiasts

---

## Version 1 Features

- Register
- Login
- Create conversation
- View conversation list
- Rename conversation
- Delete conversation

---

## Out of Scope

- AI-generated responses
- LLM providers
- Streaming
- RAG
- File upload
- Agents
- Usage analytics

---

## Success Criteria

A user should be able to:

- Register
- Authenticate
- Manage only their own conversations
- Never access another user's data


## Non-functional Requirements

- Secure authentication
- RESTful API
- Modular architecture
- Easy to extend
- Well tested
- Dockerized
